# Nero

Програма для Windows. Не вкладка браузера.

## Запуск

Потрібен Node.js 20 або новіший.

```bash
npm install
npm run desktop
```

Відкриється вікно Nero. Кнопка «Вийти на стіл» ставить її поверх інших вікон. Подвійний клік по ній на столі закриває це вікно.

Голос береться з Windows. Якщо українською тихо або англійською: Параметри → Час і мова → Мовлення → додати український голос.

GPT, Claude, Gemini і Kimi відповідають лише після ключа в налаштуваннях. Без ключа Неро відповідає локально.
